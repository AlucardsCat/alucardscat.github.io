隐私政策

应用：Soho KLCC Gmail Sync。生效日期：2026-10-17。

用途与访问范围

本应用是 Soho Suites KLCC 经营者自用的内部业务邮件接入与处理工具，服务于自有的线下住宿业务。OTA 平台将业务通知发到经营者的 Gmail 邮箱。应用接收邮箱变化通知，再按业务规则查询和读取相关 OTA 邮件，识别平台来源，在私有管理系统内提供邮件线索、分类及待处理事项。经营者据此核对并处理自己的住宿业务。程序不向公众开放注册，仅供内部人员工作使用。内部人员的系统使用权限不等于可以连接个人邮箱；当前邮件接入仅限经营者本人授权的经营邮箱。应用侧筛选不是 Google 的逐标签权限隔离；gmail.readonly 在技术上可读取整个授权邮箱。

处理的数据

处理可能涉及发件人、邮件主题和正文、接收时间、消息编号、房源及订单编号。核实订单时还可能涉及客人姓名、联系方式、住宿日期、房型、金额及订单状态。程序不申请发送或删除邮件权限。

存储与服务提供方

当前邮件接收器在 Google Cloud 运行，授权凭据由 Google Secret Manager 保管。接收器将消息编号、时间、平台、房源、订单线索及处理状态发送到受限访问的 ChatGPT Sites 管理系统。该接收器不将完整原邮件正文持久保存到候选队列。经核实的订单资料由私有管理系统保存。

Google 与 ChatGPT Sites 作为相关服务提供方参与数据处理。程序不将邮箱或订单资料公开发布，不出售这些资料，不用于广告定向，也不将 Gmail 数据用于训练通用机器学习或人工智能模型。人工核对仅用于经营者授权的具体业务。

保存与删除

授权凭据在接入期间保存。候选记录与订单资料按经营者的业务需要保留，当前未配置统一的自动删除期限。经营者可请求停用接入、撤销授权或删除可删除资料。撤销授权本身不会自动删除此前已保存的订单资料。

控制与联系

邮箱所有者可在 Google 账号的第三方连接设置中撤销本程序授权。停用或资料处理问题请联系 sherrymix.z.alucard@gmail.com。

Google API 数据使用

本程序使用和向其他应用转移通过 Google API 获取的信息，将遵守 Google API 服务用户数据政策，包括其中的 Limited Use 要求。

邮件接收与处理流程

  1. 接收 Gmail 的邮箱变化通知。通知本身不包含完整订单。
  2. 查询相关邮件变化，按 OTA 发件来源和业务内容筛选邮件。
  3. 当前程序将相关信息分为订单候选、其他业务通知和待人工核对三类，并排除规则已识别的广告。
  4. 新订单、订单修改、取消申请、正式取消和付款等具体业务类型，需要进一步核对；当前尚未实现全部类型的独立自动处理。
  5. 经核实的完整订单可通过现有导入流程进入内部订单管理，再衔接房态和库存核对。邮件接收或分类成功不代表订单已核实，也不代表 OTA 库存已更新。

无法分类、字段缺失或来源未核实的信息保留待处理，不按猜测新增订单或释放库存。业务筛选规则可能漏识别新主题或新发件来源，需要持续核对。
